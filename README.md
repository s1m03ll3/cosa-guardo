# CosaGuardo – prototipo

App per decidere cosa guardare: filtri o descrizione libera, elenco dei film disponibili sulle tue piattaforme o nelle tue liste, oppure "🎲 A caso".

Prototipo in un unico file (`index.html`), senza server: i dati (utenti, liste, preferenze) restano nel browser del dispositivo.

## Provarlo
- **Online:** apri l'indirizzo GitHub Pages del repository (vedi sotto) dal telefono.
- **Sul telefono come app:** dal browser usa *Condividi → Aggiungi a schermata Home* (iPhone/Safari) oppure *⋮ → Aggiungi a schermata Home* (Android/Chrome).
- **Dati:** parte con un catalogo demo di 42 film. Per i dati reali inserisci la tua chiave TMDB in *Profilo → 🛠 Sviluppatore*.

## Documentazione
Decisioni, schema del database, piano economico e roadmap: [PROGETTO.md](PROGETTO.md).
